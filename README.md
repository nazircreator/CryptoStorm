 📊 CryptoStorm

Красивый и понятный анализатор криптовалютного рынка. Программа собирает актуальные данные о монетах и строит наглядные круговые диаграммы, чтобы оценивать ситуацию на рынке в один клик.

---

## 🔥 Что умеет проект
*   **Анализ рынка** — собирает свежую инфу по криптовалютам.
*   **Круговые диаграммы** — красиво показывает доли и объемы монет.
*   **Быстрый старт** — запускается без сложных настроек.
